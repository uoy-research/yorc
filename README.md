# York OPM Registration Code (YORC)
A tool to perform co-registration between OPM-MEG data and MRI structural scans using a 3D scanning camera. This provides an alternative to the conventional Coil-On-Head based co-registration.

## Overview

Two 3D scans are recorded during the MEG session, one with the participant outside the MEG helmet, and one with the participant installed in the helmet with the sensors inserted. These are used in a 4-step process that ultimately registers the MEG sensor positions with the anatomy of the subjects brain in a structural MRI scan.

The overall process follows these steps:

1) Register the 3D helmet scan with known landmarks in the device coordinate system.

2) Define a head coordinate system using the pre-auricular points, and the nasion on the head-outside 3D scan.

3) Register the 3D helmet scan with the head-outside 3D scan to generate a device->head transform.

4) Register the MRI scalp surface generated by FreeSurfer with the head-outside 3D scan to generate a MRI->head transform

## Hardware
This project was developed using a Revopoint pop3 camera to record 3D images, and a FieldLine Inc. HEDscan MEG system to record OPM sensor positions and neurological MEG data.

In order to register the 3D scans with the HEDscan helmet, there must be a set of landmarks positions that can be identified in the 3D images, and which have known coordinates in the MEG device coordinate system.

This repository contains the file Landmarks.pdf which is an image with some landmark labels that can be printed, cut out, and attached to the HEDscan helmet to ease the identification of the landmark positions in the 3D scans.

## Acquiring 3D scans
Use a 3D camera to generate two colour-texture meshes of the participants head both inside the MEG helmet:

1) Outside the MEG system to achieve better coverage for registration with MRI surface

2) Inside the MEG system for registration with the MEG device coordinate system

In each case, start by directing the camera towards the participants right ear, and then circle the camera around the front of the participants head to the left ear, making sure to include the nose, eyebrows, and forehead.

A guide to acquiring the 3D scans can be found in LIDAR_Guide_for_Operators_V1.0.pdf.


## MRI data
The FreeSurfer recon-all tool can be used to segment structural MRI data T1 (+T2), and the FreeSurfer mkheadsurf utility can then be used to generate a scalp surface, which can be converted to stl format using the mris_convert utility.

## Results
The script will add a device-to-head transform into MEG data files, and generate a separate trans.fif file containing the MRI-to-head transform, in accordance with the approach used in MNE-python.


## Installation
We recommend that you run the python script in a virtual environment to ensure that the required packages are available.

```
python3 -m venv /path/to/coreg_env

source /path/to/coreg_env/bin/activate

pip3 install -r ./requirements.txt
```

## Usage
```
source /path/to/coreg_env/bin/activate

python3 ./YORC.py -om LIDAR_head_mesh.ply -im LIDAR_helmet_mesh.ply -s Freesurfer_mriscalp.stl -m MEG_run01_raw.fif MEG_run02_raw.fif -lm 1 2 3 4 5 6
```
On running the script from a terminal, instructions will be printed to the terminal for the user to mark various anatomical landmarks on cloud meshes of the head in a number of pop-up windows.

1) Helmet 3D scan - Mark the location of registration landmarks on the HEDscan helmet

2) Head 3D scan - Mark the right pre-auricular, left pre-auricular and nasion.

3) Helmet 3D scan - Mark the participant's eyes and the tip of their nose

4) Head 3D scan - Mark the participant's eyes and the tip of their nose

5) MRI scalp surface - Mark the eyes and nasion

6) Helmet 3D scan - Mark the eyes and nasion
